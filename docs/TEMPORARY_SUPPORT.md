# 임시 캐릭터 지원의 교체와 엔진 식별

마리안 : 퀸의 임시 구현은 사용자 소유 fork에서만 관리한다. 캐릭터 원문·해석·실측 한계는 해당 시나리오 문서를 정본으로 삼고, 이 문서는 변경의 수명과 배포 식별만 다룬다.

## 변경을 나누는 기준

- 작업 시작 fork 기준: 5afa8b5 (upstream/master 병합). 원본 기준: 23164e4.
- API 래퍼·Render 설정과 엔진 내용 식별은 fork의 영구 통합 부분이다. 임시 캐릭터 구현을 제거할 때 함께 되돌리지 않는다.
- 캐릭터 데이터, 해당 메커니즘, 시나리오와 전용 검사는 임시 지원 변경으로 식별 가능하게 묶는다. 무관한 캐릭터 수치나 기존 baseline을 함께 수정하지 않는다.

## 원본에 정식 지원이 들어오면

1. 이름이 추가됐다는 사실에 더해 스킬 파싱·메커니즘 구현까지 정식 지원되는지 원본 변경을 확인한다.
2. 현재 배포 상태와 임시 지원 변경을 보존한 로컬 검토 브랜치에서, 임시 변경을 제거하고 정식 구현을 병합한다. 변경이 겹친 뒤 전체 임시 커밋을 무조건 revert하면 정식 구현까지 지울 수 있으므로 파일과 JSON 키를 대조한다. reset --hard나 개인 프로필 삭제로 교체하지 않는다.
3. API 래퍼·CORS 설정·Render 연결·엔진 식별을 유지하고, 마리안 : 퀸의 동일 조건 비교와 전체 회귀 검사를 통과시킨다. 이미 존재하는 baseline을 실패를 없애려고 갱신하지 않는다.
4. 계산 서버를 새 버전으로 배포하고 /health의 commit을 확인한다. 바뀐 엔진 결과에 이전 엔진의 원시 계산·자동 계수가 재사용되지 않아야 한다.

매일 실행되는 .github/workflows/sync-upstream.yml은 원본을 fork에 병합할 뿐 임시 구현을 자동 제거하지 않는다. 충돌은 수동 조정해야 하며, 정식 지원 전환은 별도 검토 사항이다.

## 엔진 식별 계약

/health의 version은 API 래퍼 버전 0.3.0을 유지한다. commit은 프로세스 시작 때 계산한 sha256 식별값이다. data의 JSON, calculator·runner의 Python, API 요청 매핑 파일을 경로와 내용으로 해시한다. 로컬 미커밋 계산 변경과 이전 코드로의 복원도 반영된다.

문서·파일 수정 시각·환경 파일·개인 profiles·세션 쿠키·원시 수집 데이터·테스트·캐시는 포함하지 않는다. Render가 RENDER_GIT_COMMIT을 제공하면 source_commit으로 함께 반환하지만, 문서만 바꾼 배포가 계산 캐시를 무효화하지 않도록 계산 내용 식별과는 분리한다. 실행 중 파일을 바꾸는 운용은 지원하지 않으며 엔진 변경 후 프로세스를 다시 시작한다.

시뮬 응답의 engine은 그 응답을 만든 프로세스의 식별값이다. 웹앱은 이 값을 원시 결과·교체 조합·일괄 검증에 사용하고, 저장 직전 /health.commit으로 재확인한다. Apps Script도 응답 식별값과 작업 전후 health를 대조한다. 별도 health 캐시로 응답을 라벨링하지 않는다. 엔진 식별값 없는 구버전 API는 일반 예측의 기존 폴백을 유지하지만 수동 피팅은 서버 업데이트를 요구한다. 엔진 식별이 원래 없는 옛 수동 계수의 호환은 유지하므로 그 계수는 운영자가 별도 검토해야 한다. 기존 실측 스냅샷은 보존하되 다른 엔진에서 계산한 원시 결과나 검증 계수를 새 엔진 결과로 간주하지 않는다.

## 확인 명령

python -m runner.doclint
python -m runner.snapshot
python -m unittest discover -s tests

기본 snapshot 검사는 기존 golden 결과와 비교한다. --update는 별도의 의도된 기준 갱신일 때만 사용한다. 신규 캐릭터 전용 baseline을 생성할 때도 기존 baseline과 섞어 덮어쓰지 않는다.

## 배포 순서

1. 계산 엔진 fork를 먼저 배포하여 /health.commit과 /simulate의 engine이 같은 새 식별값인지 확인한다.
2. 웹앱과 다운로드용 실행기를 함께 갱신한다.
3. 웹앱 저장소 outputs/apps_script_raid_damage_correction.gs 전체를 Apps Script에 붙여 넣고 새 버전으로 배포한다. 기존 자동 검증 트리거 이름은 바뀌지 않아 재설치할 필요가 없다.
4. 마리안 : 퀸 포함 5인 시뮬이 이름 오류 없이 실행되는지, 이전 엔진의 자동 계수가 선택되지 않는지 확인한다. 정식 지원 전환 때도 같은 순서를 따른다.
